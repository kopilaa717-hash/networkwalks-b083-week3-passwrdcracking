## Steps to crack the password using john tool
- Open the Pdf hash extractor in browser.
- link: https://www.onlinehashcrack.com/tools-pdf-hash-extractor.php.
- select the encrypted pdf and click upload.
- copy the hash value into notepad and save it as hash1.txt.
- open Johnny GUI and click the open password file.
- browse the file .
- click the start attack button.
- copy the password and use that password in encrypted pdf.
- file is opened.
